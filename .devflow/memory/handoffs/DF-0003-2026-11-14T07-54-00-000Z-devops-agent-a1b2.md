## Outcome

The HTTP 502 is explained and the service is restored.

Two faults compounded. The server on port 3000 bound `127.0.0.1` only, so the
host-side Tailscale Serve proxy — which reaches the container at
`172.18.0.2:3000` — had its connection refused and answered 502, while the
application kept answering 200 on loopback. The bind had been replaced because
`playwright.config.ts` also ran its root-build E2E server on port 3000 and, with
`reuseExistingServer`, silently displaced the live preview and took the port
bound to loopback.

Fixed by serving the prefix build on port 3000 with `HOSTNAME=0.0.0.0`, detached
via `setsid -f` (PID 378890, PPID 1, own SID), and by moving the suite's root
server to port 3100 so the E2E run can never displace the published port again.
The orphaned server on port 3121 (deleted cwd) and the superseded root build
were terminated by exact PID — never by a `pkill` pattern, because several
Next.js servers run in parallel and a pattern kill would have taken the wrong
one.
