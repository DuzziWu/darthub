### Where the compiled CSS lands (corrected after task 001)
Next.js 16 defaults to **Turbopack**, which emits the CSS chunk to `.next/static/chunks/<hash>.css`. `.next/static/css/<hash>.css` is the **webpack** path (`npx next build --webpack`). The Dockerfile copies `.next/static` separately, so both paths are covered — the plan keeps the default Turbopack build and does not modify `next.config.ts`. When checking the compiled output, look in `.next/static/chunks/` (and accept `.next/static/css/` as an alternative).
