## What the reviewers confirmed as correct

- The class hierarchy is unchanged; the second constructor parameter is optional, so every
  existing call site stays source-compatible; `instanceof GameEngineStateError` still holds for
  `src/realtime/GameStateMachine.ts:41` and `src/components/x01/X01MatchView.tsx:232`.
- `git diff 2bcfa25 1724b88 -- src/game-engine/GameEngine.ts` is purely additive: nine throw
  sites gained a second argument; every condition, message and audit path is byte-identical.
- No decision anywhere is made on an engine message.
- The mapping is total at compile time (`Readonly<Record<GameEngineErrorCode, string>>`) and
  total at runtime (the test compares the keys with the union); every error without a code
  degrades to the fallback — no English developer string can reach the player.
- The change is string-only: no markup, no colour, no token, no focus change; the German
  sentences are shorter than the English messages they replace, so the status line is no taller.
  Verified in a real browser at 1440×900, 1024×768 and 390×844 (no clipping, no scrollbar,
  no page errors) by the frontend agent.
